# AI 模型目录

将训练好的 ONNX 模型放在此目录，例如：

```
models/mosaic_detector.onnx
```

## 当前状态

- **无模型也能先用**：配置里 `ai.mode: heuristic` 时，使用 OpenCV 颜色/块状统计检测绿屏花屏与明显马赛克，无需本目录任何文件。
- **真正 AI**：放入 `mosaic_detector.onnx` 后，将 `ai.mode` 设为 `auto` 或 `onnx` 即可。

## 模型约定（ONNX）

| 项目 | 约定 |
|------|------|
| 输入 | `float32`，形状 `1×3×224×224`，RGB，像素归一化到 0～1 |
| 输出 | `1×2`（[正常概率, 异常概率]）或 `1×1`（异常分数） |

训练可在其他有 GPU 的机器完成，只把 `.onnx` 拷到本目录。
